Chapter 7 Hypothesis Testing, One-Sample Inference

  • In a one-sample problem, hypotheses are specified about a single distribution.
  • In a two-sample problem, two different distributions are compared.

The null hypothesis, denoted by H0H_0H0​, is the hypothesis that is to be tested. The alternative hypothesis, denoted by H1H_1H1​ is the hypothesis that in some sense contradicts the null hypothesis.

Four possible outcomes in hypothesis testing

Truth: H0H_0H0​Truth: H1H_1H1​
Decision: Accept H0H_0H0​H0H_0H0​ is true and H0H_0H0​ is acceptedH1H_1H1​ is true and H0H_0H0​ is accepted (type II error, β\betaβ)
Decision: Reject H0H_0H0​H0H_0H0​ is true and H0H_0H0​ is rejected (type I error, α\alphaα)H1H_1H1​ is true and H0H_0H0​ is rejected (power, 1−β1-\beta1−β)
  • The probability of a type I error is the probability of rejecting the H0H_0H0​ when H0H_0H0​ is true, usually denoted by α\alphaα and is commonly referred to as the significance level of a test.
  • The probability of a type II error is the probability of accepting H0H_0H0​ when H1H_1H1​ is true, usually denoted by β\betaβ.
  • The power of a test is
    1−β=1−The probability of a type II error=P(rejecting H0∣H1 is true)1 - \beta = 1 - \text{The probability of a type II error} = P(\text{rejecting } H_0|H_1 \text{ is true})1−β=1−The probability of a type II error=P(rejecting H0​∣H1​ is true)
    The general aim in hypothesis testing is to use statistical tests that make α\alphaα and β\betaβ as small as possible.

One-sample ttt test for the mean of a normal distribution: One-Sided Alternatives​

Critical-value method​

Under H0H_0H0​, For random variable (Xˉ−μ0)/(S/n)∼tn−1(\bar{X}-\mu_0) / (S/ \sqrt n) \sim t_{n-1}(Xˉ−μ0​)/(S/n​)∼tn−1​, thus P(tn−1<tn−1,α)=αP(t_{n-1} < t_{n-1, \alpha}) = \alphaP(tn−1​<tn−1,α​)=α. To test H0:μ=μ0H_0: \mu = \mu_0H0​:μ=μ0​ (σ\sigmaσ unknown) vs. H1:μ<μ0H_1: \mu < \mu_0H1​:μ<μ0​ (σ\sigmaσ unknown) with a specified significance level α\alphaα, compute the value

t=xˉ−μ0s/nt = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}t=s/n​xˉ−μ0​​
  • If t<tn−1, αt < t_{n-1,\, \alpha}t<tn−1,α​, reject H0H_0H0​. Which means the sample results is extremely rare under H0H_0H0​, less than α\alphaα, it's unusual.
  • If t≥tn−1, αt \geq t_{n-1,\, \alpha}t≥tn−1,α​, accept H0H_0H0​.

Some concepts

  • The value ttt in Equation 7.2 is a test statistic; the test procedure is based on this statistic.
  • The value tn−1, αt_{n-1,\, \alpha}tn−1,α​ is a critical value; if t<tn−1, αt < t_{n-1,\, \alpha}t<tn−1,α​, reject H0H_0H0​; if t≥tn−1, αt \geq t_{n-1,\, \alpha}t≥tn−1,α​, accept H0H_0H0​.
  • Computing a test statistic and comparing it with a critical value determined by the type I error is the critical-value method of hypothesis testing.
  • Traditionally, an α\alphaα level of exactly .05 is used most frequently.

p-value method​

We can also compute ppp-value: the α\alphaα level at which the given value of the test statistic (such as ttt) is on the borderline between the acceptance and rejection regions:

p=P(tn−1≤t)p = P(t_{n-1} \leq t)p=P(tn−1​≤t)

Thus ppp is the area to the left of ttt under a tn−1t_{n−1}tn−1​ distribution. Given the above formula, The ppp-value can also be thought of as the probability of obtaining a test statistic as extreme as or more extreme than the actual test statistic obtained, given that the null hypothesis is true. For the above figure, we know ttt statistic follows a tn−1t_{n-1}tn−1​ distribution. Hence the probability of obtaining a ttt statistic that is no larger than the actual ttt under H0H_0H0​ is P(tn−1≤t)=pP(t_{n-1} \leq t)=pP(tn−1​≤t)=p-value.

ppp-value tells us exactly how significant our results are without performing repeated significance tests at different α\alphaα levels (like α=0.05,0.1,...\alpha = 0.05, 0.1, ...α=0.05,0.1,...)

Guidelines for judging the significance of a ppp-value

  • If .01≤p<.05.01 \le p < .05.01≤p<.05, the results are significant.
  • If .001≤p<.01.001 \le p < .01.001≤p<.01, the results are highly significant.
  • If p<.001p < .001p<.001, the results are very highly significant.
  • If p>.05p > .05p>.05, the results are not statistically significant (sometimes denoted NS).
  • If .05≤p<.10.05 \le p < .10.05≤p<.10, a trend toward statistical significance is sometimes noted.

In many situations, we wish to use an alternative hypothesis that μ>μ0\mu > \mu_0μ>μ0​, To test H0:μ=μ0H_0: \mu = \mu_0H0​:μ=μ0​ (σ\sigmaσ unknown) vs. H1:μ>μ0H_1: \mu > \mu_0H1​:μ>μ0​ (σ\sigmaσ unknown) with significance level α\alphaα, compute

t=xˉ−μ0s/nt = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}t=s/n​xˉ−μ0​​
  • If t>tn−1, 1−αt > t_{n-1,\, 1-\alpha}t>tn−1,1−α​, reject H0H_0H0​.
  • If t≤tn−1, 1−αt \le t_{n-1,\, 1-\alpha}t≤tn−1,1−α​, accept H0H_0H0​.

The ppp-value is

p=P(tn−1>t)p = P(t_{n-1} > t)p=P(tn−1​>t)

One-sample ttt test for the mean of a normal distribution: Two-Sided Alternatives​

In the previous section the alternative hypothesis was assumed to be in a specific direction relative to the null hypothesis (μ>μ0\mu > \mu_0μ>μ0​ or μ<μ0\mu < \mu_0μ<μ0​). In most instances this prior knowledge is unavailable.

A two-tailed test is a test in which the values of the parameter being studied (in this case μ\muμ) under the alternative hypothesis are allowed to be either greater than or less than the value of the parameter under the null hypothesis (μ0\mu_0μ0​).

For a two-sided alternative, a reasonable decision rule is to reject H0H_0H0​ if the test statistic ttt is either too small or too large. That is, reject H0H_0H0​ if t<c1t < c_1t<c1​ or t>c2t > c_2t>c2​, and accept H0H_0H0​ if c1≤t≤c2c_1 \le t \le c_2c1​≤t≤c2​.

The constants c1c_1c1​ and c2c_2c2​ are chosen so that the total type I error is α\alphaα:

P(reject H0∣H0 true)=P(tn−1<c1∣H0 true)+P(tn−1>c2∣H0 true)=αP(\text{reject } H_0 \mid H_0 \text{ true}) = P(t_{n-1} < c_1 \mid H_0 \text{ true}) + P(t_{n-1} > c_2 \mid H_0 \text{ true}) = \alphaP(reject H0​∣H0​ true)=P(tn−1​<c1​∣H0​ true)+P(tn−1​>c2​∣H0​ true)=α

For a two-tailed test, half of the type I error is placed in each tail:

P(tn−1<c1∣H0 true)=P(tn−1>c2∣H0 true)=α/2P(t_{n-1} < c_1 \mid H_0 \text{ true}) = P(t_{n-1} > c_2 \mid H_0 \text{ true}) = \alpha/2P(tn−1​<c1​∣H0​ true)=P(tn−1​>c2​∣H0​ true)=α/2

Under H0H_0H0​,

P(tn−1<tn−1, α/2)=P(tn−1>tn−1, 1−α/2)=α/2P(t_{n-1} < t_{n-1,\, \alpha/2}) = P(t_{n-1} > t_{n-1,\, 1-\alpha/2}) = \alpha/2P(tn−1​<tn−1,α/2​)=P(tn−1​>tn−1,1−α/2​)=α/2

Therefore,

c1=tn−1, α/2=−tn−1, 1−α/2,c2=tn−1, 1−α/2c_1 = t_{n-1,\, \alpha/2} = -t_{n-1,\, 1-\alpha/2}, \quad c_2 = t_{n-1,\, 1-\alpha/2}c1​=tn−1,α/2​=−tn−1,1−α/2​,c2​=tn−1,1−α/2​

One-sample ttt test for a two-sided alternative: to test H0:μ=μ0H_0: \mu = \mu_0H0​:μ=μ0​ vs. H1:μ≠μ0H_1: \mu \ne \mu_0H1​:μ=μ0​ with significance level α\alphaα, compute

t=xˉ−μ0s/nt = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}t=s/n​xˉ−μ0​​
  • If ∣t∣>tn−1, 1−α/2|t| > t_{n-1,\, 1-\alpha/2}∣t∣>tn−1,1−α/2​, reject H0H_0H0​.
  • If ∣t∣≤tn−1, 1−α/2|t| \le t_{n-1,\, 1-\alpha/2}∣t∣≤tn−1,1−α/2​, accept H0H_0H0​.

Alternatively, we might want to compute a ppp-value as we did in the one-sided case.

ppp-value for the two-sided one-sample ttt test: let

t=xˉ−μ0s/nt = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}t=s/n​xˉ−μ0​​

Then

p={2P(tn−1≤t),if t≤02[1−P(tn−1≤t)],if t>0p = \begin{cases} 2P(t_{n-1} \le t), & \text{if } t \le 0 \\ 2\left[1 - P(t_{n-1} \le t)\right], & \text{if } t > 0 \end{cases}p={2P(tn−1​≤t),2[1−P(tn−1​≤t)],​if t≤0if t>0​

In words, if t≤0t \le 0t≤0, the ppp-value is two times the area to the left of ttt under a tn−1t_{n-1}tn−1​ distribution. If t>0t > 0t>0, the ppp-value is two times the area to the right of ttt.

For a two-sided alternative, the ppp-value is the probability under H0H_0H0​ of obtaining a test statistic as extreme as or more extreme than the observed test statistic. Because the alternative is two-sided, extremeness is measured by the absolute value of the test statistic.

The power of a test​

One-Sided Alternatives: μ1\mathbf{\mu_1}μ1​ less than μ0\mathbf{\mu_0}μ0​​

Suppose H0:μ=μ0H_0: \mu = \mu_0H0​:μ=μ0​ vs. H1:μ=μ1H_1: \mu = \mu_1H1​:μ=μ1​. (μ1<μ0\mu_1 < \mu_0μ1​<μ0​) where the underlying distribution was assumed to be normal and the population variance was assumed to be known. Under H0H_0H0​,

Z=(Xˉ−μ0)/(σ/n)∼N(0,1)Z = (\bar{X}-\mu_0) / (\sigma / \sqrt{n}) \sim N(0,1)Z=(Xˉ−μ0​)/(σ/n​)∼N(0,1)

We can calculate test statistic zzz, and for a type I error of α\alphaα, H0H_0H0​ is rejected if z<zαz < z_{\alpha}z<zα​ and H0H_0H0​ is accepted if z≥zαz ≥ z_{\alpha}z≥zα​.

The power of the test is the probability of rejecting H0H_0H0​ when H1H_1H1​ is true. If the true mean under H1H_1H1​ is μ1\mu_1μ1​, then

Power=P(reject H0∣H1 True)=P(Z<zα∣μ=μ1)=P(Xˉ−μ0σ/n<zα∣μ=μ1)=P(Xˉ<μ0+zασn∣μ=μ1)\begin{aligned} \text{Power} &= P(\text{reject } H_0 \mid H_1 \text{ True}) \\ &= P(Z < z_{\alpha} \mid \mu = \mu_1) \\ &= P\left(\frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} < z_{\alpha} \mid \mu = \mu_1\right) \\ &= P\left(\bar{X} < \mu_0 + z_{\alpha}\frac{\sigma}{\sqrt{n}} \mid \mu = \mu_1\right) \end{aligned}Power​=P(reject H0​∣H1​ True)=P(Z<zα​∣μ=μ1​)=P(σ/n​Xˉ−μ0​​<zα​∣μ=μ1​)=P(Xˉ<μ0​+zα​n​σ​∣μ=μ1​)​

Under H1H_1H1​, Xˉ∼N(μ1,σ2n)\bar{X} \sim N\left(\mu_1, \frac{\sigma^2}{n}\right)Xˉ∼N(μ1​,nσ2​). After standardizing the limit,

Power=Φ(μ0+zασ/n−μ1σ/n)=Φ(zα+μ0−μ1σn)\text{Power} = \Phi\left(\frac{\mu_0 + z_{\alpha}\sigma/\sqrt{n} - \mu_1}{\sigma/\sqrt{n}}\right) = \Phi\left(z_{\alpha} + \frac{\mu_0 - \mu_1}{\sigma}\sqrt{n}\right)Power=Φ(σ/n​μ0​+zα​σ/n​−μ1​​)=Φ(zα​+σμ0​−μ1​​n​)

IMPORTANT: The power of a test tells us how likely it is that a statistically significant difference will be detected based on a finite sample size nnn. If the power is too low, then there is little chance of finding a significant difference and nonsignificant results are likely even if real differences exist between the true mean μ\muμ of the group being studied and the null mean μ0\mu_0μ0​.

Example: Birthweight data Compute the power of the test for the birthweight data with an alternative mean of 115115115 oz and α=.05\alpha = .05α=.05, assuming the true standard deviation is σ=24\sigma = 24σ=24 oz. We have μ0=120\mu_0 = 120μ0​=120 oz, μ1=115\mu_1 = 115μ1​=115 oz, α=.05\alpha = .05α=.05, σ=24\sigma = 24σ=24, and n=100n = 100n=100. Thus,

Power=Φ[z.05+(120−115)10024]=Φ[−1.645+5(10)24]=Φ(0.438)=.669\begin{aligned} \text{Power} &= \Phi\left[z_{.05} + \frac{(120 - 115)\sqrt{100}}{24}\right] \\ &= \Phi\left[-1.645 + \frac{5(10)}{24}\right] \\ &= \Phi(0.438) \\ &= .669 \end{aligned}Power​=Φ[z.05​+24(120−115)100​​]=Φ[−1.645+245(10)​]=Φ(0.438)=.669​

Therefore, there is about a 67%67\%67% chance of detecting a significant difference using a 5%5\%5% significance level with this sample size.

One-Sided Alternatives: μ1\mathbf{\mu_1}μ1​ greater than μ0\mathbf{\mu_0}μ0​​

Suppose H0:μ=μ0H_0: \mu = \mu_0H0​:μ=μ0​ vs. H1:μ=μ1H_1: \mu = \mu_1H1​:μ=μ1​. (μ1>μ0\mu_1 > \mu_0μ1​>μ0​) H0H_0H0​ is rejected if z>z1−αz > z_{1 - \alpha}z>z1−α​ and H0H_0H0​ is accepted if z≤z1−αz \leq z_{1-\alpha}z≤z1−α​.

Power=P(reject H0∣H1 True)=P(Z>z1−α∣μ=μ1)=P(Xˉ−μ0σ/n>z1−α∣μ=μ1)=P(Xˉ>μ0+z1−ασn∣μ=μ1)=1−P(Xˉ<μ0+z1−ασn∣μ=μ1)=1−Φ(μ0+z1−ασ/n−μ1σ/n)=1−Φ(z1−α+(μ0−μ1)nσ)\begin{aligned} \text{Power} &= P(\text{reject } H_0 \mid H_1 \text{ True}) \\ &= P(Z > z_{1-\alpha} \mid \mu = \mu_1) \\ &= P\left(\frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} > z_{1-\alpha} \mid \mu = \mu_1\right) \\ &= P\left(\bar{X} > \mu_0 + z_{1-\alpha}\frac{\sigma}{\sqrt{n}} \mid \mu = \mu_1\right) \\ &= 1-P\left(\bar{X} < \mu_0 + z_{1-\alpha}\frac{\sigma}{\sqrt{n}} \mid \mu = \mu_1\right) \\ &= 1 - \Phi\left(\frac{\mu_0 + z_{1-\alpha}\sigma/\sqrt{n} - \mu_1}{\sigma/\sqrt{n}}\right) \\ &= 1 - \Phi\left(z_{1-\alpha} + \frac{(\mu_0 - \mu_1)\sqrt{n}}{\sigma}\right) \end{aligned}Power​=P(reject H0​∣H1​ True)=P(Z>z1−α​∣μ=μ1​)=P(σ/n​Xˉ−μ0​​>z1−α​∣μ=μ1​)=P(Xˉ>μ0​+z1−α​n​σ​∣μ=μ1​)=1−P(Xˉ<μ0​+z1−α​n​σ​∣μ=μ1​)=1−Φ(σ/n​μ0​+z1−α​σ/n​−μ1​​)=1−Φ(z1−α​+σ(μ0​−μ1​)n​​)​

Using the relationships Φ(−x)=1−Φ(x)\Phi(-x) = 1 - \Phi(x)Φ(−x)=1−Φ(x) and zα=−z1−αz_{\alpha} = -z_{1-\alpha}zα​=−z1−α​, the power expression can also be rewritten as

Φ[−z1−α+(μ1−μ0)nσ]=Φ[zα+(μ1−μ0)nσ],if μ1>μ0\Phi\left[-z_{1-\alpha} + \frac{(\mu_1 - \mu_0)\sqrt{n}}{\sigma}\right] = \Phi\left[z_{\alpha} + \frac{(\mu_1 - \mu_0)\sqrt{n}}{\sigma}\right], \quad \text{if } \mu_1 > \mu_0Φ[−z1−α​+σ(μ1​−μ0​)n​​]=Φ[zα​+σ(μ1​−μ0​)n​​],if μ1​>μ0​

Summery: Power for the one-sample zzz test with known variance​

For the hypothesis H0:μ=μ0H_0: \mu = \mu_0H0​:μ=μ0​ vs. H1:μ=μ1H_1: \mu = \mu_1H1​:μ=μ1​, where the underlying distribution is normal and the population variance σ2\sigma^2σ2 is known, the power is

Power=Φ(zα+∣μ0−μ1∣nσ)=Φ(−z1−α+∣μ0−μ1∣nσ)\text{Power} = \Phi\left(z_{\alpha} + \frac{|\mu_0 - \mu_1|\sqrt{n}}{\sigma}\right) = \Phi\left(-z_{1-\alpha} + \frac{|\mu_0 - \mu_1|\sqrt{n}}{\sigma}\right)Power=Φ(zα​+σ∣μ0​−μ1​∣n​​)=Φ(−z1−α​+σ∣μ0​−μ1​∣n​​)

The power depends on four factors: significance level α\alphaα, effect size ∣μ0−μ1∣|\mu_0 - \mu_1|∣μ0​−μ1​∣, sample size nnn, and standard deviation σ\sigmaσ.

Factors affecting the power

  1. If the significance level decreases (α\alphaα decreases), then zαz_{\alpha}zα​ increases and the power decreases.
  2. If the alternative mean is farther from the null mean (∣μ0−μ1∣|\mu_0 - \mu_1|∣μ0​−μ1​∣ increases), then the power increases.
  3. If the standard deviation increases (σ\sigmaσ increases), then the power decreases.
  4. If the sample size increases (nnn increases), then the power increases.

Power Curve​

For given levels of α=.05\alpha = .05α=.05, σ=24\sigma = 24σ=24 oz, n=100n = 100n=100, and μ0=120\mu_0 = 120μ0​=120 oz, a power curve can be drawn for the power of the test under various alternative means μ1\mu_1μ1​.

For the birthweight data in Example 7.2, the power ranges from 99% when μ=110\mu = 110μ=110 oz to about 20% when μ=118\mu = 118μ=118 oz.

Two-Sided Alternatives​

Power for the one-sample zzz test for the mean of a normal distribution​

For the two-sided test

H0:μ=μ0vs.H1:μ≠μ0H_0: \mu = \mu_0 \quad \text{vs.} \quad H_1: \mu \neq \mu_0H0​:μ=μ0​vs.H1​:μ=μ0​

with a specific alternative μ=μ1\mu = \mu_1μ=μ1​, where the underlying distribution is normal and the population variance σ2\sigma^2σ2 is known, the exact power is

Power=Φ[−z1−α/2+(μ0−μ1)nσ]+Φ[−z1−α/2+(μ1−μ0)nσ]\text{Power} = \Phi\left[-z_{1-\alpha/2} + \frac{(\mu_0 - \mu_1)\sqrt{n}}{\sigma}\right] + \Phi\left[-z_{1-\alpha/2} + \frac{(\mu_1 - \mu_0)\sqrt{n}}{\sigma}\right]Power=Φ[−z1−α/2​+σ(μ0​−μ1​)n​​]+Φ[−z1−α/2​+σ(μ1​−μ0​)n​​]

This is approximately

Power≈Φ[−z1−α/2+∣μ0−μ1∣nσ]\text{Power} \approx \Phi\left[-z_{1-\alpha/2} + \frac{|\mu_0 - \mu_1|\sqrt{n}}{\sigma}\right]Power≈Φ[−z1−α/2​+σ∣μ0​−μ1​∣n​​]

Derivation To see this, for a two-sided zzz test we reject H0H_0H0​ if

z=Xˉ−μ0σ/n<zα/2orz=Xˉ−μ0σ/n>z1−α/2z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} < z_{\alpha/2} \quad \text{or} \quad z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} > z_{1-\alpha/2}z=σ/n​Xˉ−μ0​​<zα/2​orz=σ/n​Xˉ−μ0​​>z1−α/2​

Multiplying each inequality by σ/n\sigma/\sqrt{n}σ/n​ and adding μ0\mu_0μ0​, the rejection criteria can be written in terms of xˉ\bar{x}xˉ as

xˉ<μ0+zα/2σnorxˉ>μ0+z1−α/2σn\bar{x} < \mu_0 + z_{\alpha/2}\frac{\sigma}{\sqrt{n}} \quad \text{or} \quad \bar{x} > \mu_0 + z_{1-\alpha/2}\frac{\sigma}{\sqrt{n}}xˉ<μ0​+zα/2​n​σ​orxˉ>μ0​+z1−α/2​n​σ​

The power of the test against the specific alternative μ=μ1\mu = \mu_1μ=μ1​ is

Power=P(Xˉ<μ0+zα/2σn∣μ=μ1)+P(Xˉ>μ0+z1−α/2σn∣μ=μ1)=Φ(μ0+zα/2σ/n−μ1σ/n)+1−Φ(μ0+z1−α/2σ/n−μ1σ/n)=Φ[zα/2+(μ0−μ1)nσ]+1−Φ[z1−α/2+(μ0−μ1)nσ]\begin{aligned} \text{Power} &= P\left(\bar{X} < \mu_0 + z_{\alpha/2}\frac{\sigma}{\sqrt{n}} \mid \mu = \mu_1\right) + P\left(\bar{X} > \mu_0 + z_{1-\alpha/2}\frac{\sigma}{\sqrt{n}} \mid \mu = \mu_1\right) \\ &= \Phi\left(\frac{\mu_0 + z_{\alpha/2}\sigma/\sqrt{n} - \mu_1}{\sigma/\sqrt{n}}\right) + 1 - \Phi\left(\frac{\mu_0 + z_{1-\alpha/2}\sigma/\sqrt{n} - \mu_1}{\sigma/\sqrt{n}}\right) \\ &= \Phi\left[z_{\alpha/2} + \frac{(\mu_0 - \mu_1)\sqrt{n}}{\sigma}\right] + 1 - \Phi\left[z_{1-\alpha/2} + \frac{(\mu_0 - \mu_1)\sqrt{n}}{\sigma}\right] \end{aligned}Power​=P(Xˉ<μ0​+zα/2​n​σ​∣μ=μ1​)+P(Xˉ>μ0​+z1−α/2​n​σ​∣μ=μ1​)=Φ(σ/n​μ0​+zα/2​σ/n​−μ1​​)+1−Φ(σ/n​μ0​+z1−α/2​σ/n​−μ1​​)=Φ[zα/2​+σ(μ0​−μ1​)n​​]+1−Φ[z1−α/2​+σ(μ0​−μ1​)n​​]​

Using the relationship 1−Φ(x)=Φ(−x)1 - \Phi(x) = \Phi(-x)1−Φ(x)=Φ(−x), the last two terms can be combined as

Power=Φ[zα/2+(μ0−μ1)nσ]+Φ[−z1−α/2+(μ1−μ0)nσ]\text{Power} = \Phi\left[z_{\alpha/2} + \frac{(\mu_0 - \mu_1)\sqrt{n}}{\sigma}\right] + \Phi\left[-z_{1-\alpha/2} + \frac{(\mu_1 - \mu_0)\sqrt{n}}{\sigma}\right]Power=Φ[zα/2​+σ(μ0​−μ1​)n​​]+Φ[−z1−α/2​+σ(μ1​−μ0​)n​​]

Finally, because zα/2=−z1−α/2z_{\alpha/2} = -z_{1-\alpha/2}zα/2​=−z1−α/2​, we have

Power=Φ[−z1−α/2+(μ0−μ1)nσ]+Φ[−z1−α/2+(μ1−μ0)nσ]\text{Power} = \Phi\left[-z_{1-\alpha/2} + \frac{(\mu_0 - \mu_1)\sqrt{n}}{\sigma}\right] + \Phi\left[-z_{1-\alpha/2} + \frac{(\mu_1 - \mu_0)\sqrt{n}}{\sigma}\right]Power=Φ[−z1−α/2​+σ(μ0​−μ1​)n​​]+Φ[−z1−α/2​+σ(μ1​−μ0​)n​​]

Note: The exact two-sided power formula is more tedious to use than is usually necessary. Specifically, if μ1<μ0\mu_1 < \mu_0μ1​<μ0​, then the second term is usually negligible relative to the first term. However, if μ1>μ0\mu_1 > \mu_0μ1​>μ0​, then the first term is usually negligible relative to the second term. Therefore, the approximate power formula is usually used for a two-sided test because it represents the dominant term in the exact formula.

Sample-Size Determination​

One-Sided Alternatives​

The problem of determining sample size can be summarized as follows: Given that a one-sided significance test will be conducted at level α\alphaα and that the true alternative mean is expected to be μ1\mu_1μ1​, what sample size is needed to be able to detect a significant difference with probability 1−β1 - \beta1−β? Typical values for the desired power are 80%, 90%, ..., and so forth.

For a one-sided test, we set the desired power equal to 1−β1 - \beta1−β:

Power=Φ(zα+∣μ0−μ1∣nσ)=1−β\text{Power} = \Phi\left(z_{\alpha} + \frac{|\mu_0 - \mu_1|\sqrt{n}}{\sigma}\right) = 1 - \betaPower=Φ(zα​+σ∣μ0​−μ1​∣n​​)=1−β

We want to solve for nnn in terms of α\alphaα, β\betaβ, ∣μ0−μ1∣|\mu_0 - \mu_1|∣μ0​−μ1​∣, and σ\sigmaσ. Since

Φ(z1−β)=1−β\Phi(z_{1-\beta}) = 1 - \betaΦ(z1−β​)=1−β

we have

zα+∣μ0−μ1∣nσ=z1−βz_{\alpha} + \frac{|\mu_0 - \mu_1|\sqrt{n}}{\sigma} = z_{1-\beta}zα​+σ∣μ0​−μ1​∣n​​=z1−β​

Subtract zαz_{\alpha}zα​ from both sides and multiply by σ/∣μ0−μ1∣\sigma/|\mu_0 - \mu_1|σ/∣μ0​−μ1​∣:

n=(−zα+z1−β)σ∣μ0−μ1∣\sqrt{n} = \frac{(-z_{\alpha} + z_{1-\beta})\sigma}{|\mu_0 - \mu_1|}n​=∣μ0​−μ1​∣(−zα​+z1−β​)σ​

Since −zα=z1−α-z_{\alpha} = z_{1-\alpha}−zα​=z1−α​, squaring both sides gives

n=(z1−α+z1−β)2σ2(μ0−μ1)2n = \frac{(z_{1-\alpha} + z_{1-\beta})^2\sigma^2}{(\mu_0 - \mu_1)^2}n=(μ0​−μ1​)2(z1−α​+z1−β​)2σ2​

Factors affecting the sample size

  1. The sample size increases as σ2\sigma^2σ2 increases.
  2. The sample size increases as the significance level is made smaller (α\alphaα decreases).
  3. The sample size increases as the required power increases (1−β1 - \beta1−β increases).
  4. The sample size decreases as the absolute distance between the null and alternative means, ∣μ0−μ1∣|\mu_0 - \mu_1|∣μ0​−μ1​∣, increases.

Note: Sample-size estimates are usually only ballpark estimates because μ1\mu_1μ1​ and σ2\sigma^2σ2 are often unknown. These values may be estimated from previous studies, similar experiments, prior knowledge, or a small pilot study. In practice, sample-size calculations are often used to check whether the proposed sample size is reasonably close to what is needed, rather than to determine an exact number.

Two-Sided Alternatives​

The one-sided sample-size formula is appropriate when the direction of the alternative mean is specified in advance. If it is not known whether the alternative mean μ1\mu_1μ1​ is greater than or less than the null mean μ0\mu_0μ0​, then a two-sided test is appropriate.

For testing

H0:μ=μ0vs.H1:μ≠μ0H_0: \mu = \mu_0 \quad \text{vs.} \quad H_1: \mu \neq \mu_0H0​:μ=μ0​vs.H1​:μ=μ0​

with significance level α\alphaα and desired power 1−β1 - \beta1−β, the sample size needed is

n=σ2(z1−β+z1−α/2)2(μ0−μ1)2n = \frac{\sigma^2\left(z_{1-\beta} + z_{1-\alpha/2}\right)^2}{(\mu_0 - \mu_1)^2}n=(μ0​−μ1​)2σ2(z1−β​+z1−α/2​)2​

To see this, use the approximate power formula for a two-sided test and solve for nnn:

Φ(−z1−α/2+∣μ0−μ1∣nσ)=1−β\Phi\left(-z_{1-\alpha/2} + \frac{|\mu_0 - \mu_1|\sqrt{n}}{\sigma}\right) = 1 - \betaΦ(−z1−α/2​+σ∣μ0​−μ1​∣n​​)=1−β

Since Φ(z1−β)=1−β\Phi(z_{1-\beta}) = 1 - \betaΦ(z1−β​)=1−β, we have

−z1−α/2+∣μ0−μ1∣nσ=z1−β-z_{1-\alpha/2} + \frac{|\mu_0 - \mu_1|\sqrt{n}}{\sigma} = z_{1-\beta}−z1−α/2​+σ∣μ0​−μ1​∣n​​=z1−β​

Add z1−α/2z_{1-\alpha/2}z1−α/2​ to both sides and multiply by σ/∣μ0−μ1∣\sigma/|\mu_0 - \mu_1|σ/∣μ0​−μ1​∣:

n=(z1−β+z1−α/2)σ∣μ0−μ1∣\sqrt{n} = \frac{\left(z_{1-\beta} + z_{1-\alpha/2}\right)\sigma}{|\mu_0 - \mu_1|}n​=∣μ0​−μ1​∣(z1−β​+z1−α/2​)σ​

Squaring both sides gives

n=(z1−β+z1−α/2)2σ2(μ0−μ1)2n = \frac{\left(z_{1-\beta} + z_{1-\alpha/2}\right)^2\sigma^2}{(\mu_0 - \mu_1)^2}n=(μ0​−μ1​)2(z1−β​+z1−α/2​)2σ2​

This required sample size is always larger than the corresponding sample size for a one-sided test, because z1−α/2>z1−αz_{1-\alpha/2} > z_{1-\alpha}z1−α/2​>z1−α​.

Based on CI Width​

Sometimes the treatment effect is already believed to exist, so the main goal is not hypothesis testing but estimating the effect with a desired degree of precision. In this case, sample size can be chosen based on the desired width of a confidence interval.

Example: Cardiology Suppose propranolol is known to lower heart rate over 48 hours in patients with angina at standard dosage levels. A new study uses a higher dose, and investigators want to estimate the drop in heart rate with high precision.

If precision is measured by the width of a two-sided 100(1−α)%100(1-\alpha)\%100(1−α)% confidence interval, then the CI for the true mean decline μ\muμ is

xˉ±tn−1,1−α/2sn\bar{x} \pm t_{n-1,1-\alpha/2}\frac{s}{\sqrt{n}}xˉ±tn−1,1−α/2​n​s​

The width of this interval is

2tn−1,1−α/2sn2t_{n-1,1-\alpha/2}\frac{s}{\sqrt{n}}2tn−1,1−α/2​n​s​

If we want the CI width to be no wider than LLL, then

2tn−1,1−α/2sn=L2t_{n-1,1-\alpha/2}\frac{s}{\sqrt{n}} = L2tn−1,1−α/2​n​s​=L

so

n=4tn−1,1−α/22s2L2n = \frac{4t_{n-1,1-\alpha/2}^2s^2}{L^2}n=L24tn−1,1−α/22​s2​

Because tn−1,1−α/2t_{n-1,1-\alpha/2}tn−1,1−α/2​ is often approximated by z1−α/2z_{1-\alpha/2}z1−α/2​, the required sample size is approximately

n=4z1−α/22s2L2n = \frac{4z_{1-\alpha/2}^2s^2}{L^2}n=L24z1−α/22​s2​

Example: Cardiology

Find the minimum sample size needed to estimate the change in heart rate μ\muμ if the two-sided 95%95\%95% CI for μ\muμ must be no wider than 555 beats per minute and the sample standard deviation for change in heart rate is s=10s = 10s=10 beats per minute.

We have α=.05\alpha = .05α=.05, s=10s = 10s=10, and L=5L = 5L=5. Therefore,

n=4z.9752(10)2(5)2=4(1.96)2(100)25=61.5\begin{aligned} n &= \frac{4z_{.975}^2(10)^2}{(5)^2} \\ &= \frac{4(1.96)^2(100)}{25} \\ &= 61.5 \end{aligned}n​=(5)24z.9752​(10)2​=254(1.96)2(100)​=61.5​

Thus, at least 62 patients need to be studied.

The Relationship Between Hypothesis Testing and Confidence Intervals​

Two-Sided Case​

Suppose we are testing

H0:μ=μ0vs.H1:μ≠μ0H_0: \mu = \mu_0 \quad \text{vs.} \quad H_1: \mu \neq \mu_0H0​:μ=μ0​vs.H1​:μ=μ0​

For a two-sided level α\alphaα test:

  • H0H_0H0​ is rejected if and only if the two-sided 100(1−α)%100(1-\alpha)\%100(1−α)% confidence interval for μ\muμ does not contain μ0\mu_0μ0​.
  • H0H_0H0​ is accepted if and only if the two-sided 100(1−α)%100(1-\alpha)\%100(1−α)% confidence interval for μ\muμ does contain μ0\mu_0μ0​.

Note: The hypothesis-testing approach and the confidence-interval approach often lead to the same conclusion, but they emphasize different information. A p-value tells us how statistically significant the result is, while a confidence interval shows the likely range of the parameter and helps judge the practical size of the effect. Therefore, it is good practice to report both the p-value and the confidence interval whenever possible.

Example: Cardiovascular Disease For the cholesterol data, the p-value of .037.037.037 tells us how statistically significant the result is. The 95%95\%95% confidence interval for μ\muμ, (173.58,189.46)(173.58, 189.46)(173.58,189.46), gives a range of likely values that μ\muμ might assume. These two types of information are complementary.
